## 行为与边界

管理员在已保存的 IQ 配置中选择一个参与检测的活跃 OpenAI 分组后，必须确认费用提示才能启动重测。请求带 `confirm_cost=true` 和确认时看到的单次额度；服务端拒绝缺少确认、确认额度已经低于当前保存额度、无效分组、运行中的全局检测及同组五分钟内重复请求。

手动与定时检测共用数据库互斥、专用身份、分组授权、请求预算预留、用量关联和最终结算。手动重测允许在定时开关关闭时执行，但不会创建身份、扩展授权、绕过余额、价格可用性或每日预算。显示给管理员的金额是本次预算预留和事前估价阈值，不是外部提供商实际费用的绝对上限；异常或迟到用量仍按既有保留和结算规则处理。

运行历史以 `manual` 标记。手动完成的正确或错误结果可成为用户页同模型同分组的最新有效结果；失败、跳过或待处理结果不会覆盖此前有效结果。定时到期判断只看最近的 `scheduled` 轮，手动轮不会推迟下一次定时检测。
