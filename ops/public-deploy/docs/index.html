创建 API Key

API Key 是你的调用凭证，可以理解成“接口密码”。别人拿到你的 Key 后，可能会消耗你的余额，所以不要把 Key 发到群聊、截图、公开代码仓库或视频里。

  1. 打开 API 密钥页面。
  2. 点击创建 API Key。
  3. 复制生成的 Key。
  4. 把 Key 填到客户端的 API Key / Token 位置。
项目 填写内容
Base URL https://api.fluterapi.top/v1
API Key 你在 API 密钥页面创建的 Key
鉴权格式 Authorization: Bearer 你的_API_Key

Codex 和 CCSwitch

如果你是为了使用 Codex，推荐安装 Codex Desktop，并配合 CCSwitch 管理本站的 API Key、Base URL 和模型。新手不需要安装命令行版 Codex，也不需要手动改复杂配置文件。

安装 Codex Desktop

  1. 打开 OpenAI 官方 Codex 页面：https://chatgpt.com/zh-Hans-CN/codex/。
  2. 按页面提示下载并安装 Codex Desktop。
  3. 安装完成后先打开一次 Codex Desktop，确认软件能正常启动。
这份教程面向 Codex Desktop 用户，不要求安装 CLI，也不要求执行命令行安装步骤。

安装 CCSwitch

下载地址可以从 CCSwitch 官网 进入。Windows 优先选 MSI，macOS 优先选 DMG。

用本站一键导入

  1. 登录本站控制台。
  2. 打开 API 密钥页面。
  3. 创建或复制你的 API Key。
  4. 点击“导入到 CCS”。
  5. 浏览器询问是否打开 CCSwitch 时，选择允许。
  6. 导入后关闭并重新打开 Codex Desktop，让新配置生效。
你给用户解释时可以这么说：先安装 Codex Desktop，再用 CCSwitch 导入本站 API Key 和 Base URL。本站负责提供可调用的 API，CCSwitch 负责把配置填到 Codex Desktop 里。

手动配置

如果你的客户端没有一键导入，就手动填下面几项。

字段 值
Base URL / API Host https://api.fluterapi.top/v1
API Key / Token 你自己创建的 API Key
文本接口 优先 Responses，不支持时用 Chat Completions
图片接口 /v1/images/generations 
model = "gpt-5.4"
model_provider = "fluterapi"
model_reasoning_effort = "medium"
disable_response_storage = true

[model_providers.fluterapi]
name = "fluterAPI"
base_url = "https://api.fluterapi.top/v1"
wire_api = "responses"
requires_openai_auth = true

图片生成

生图需要 API Key 所在分组开启图片生成能力。当前推荐模型名是 gpt-image-2。 

curl https://api.fluterapi.top/v1/images/generations \
  -H "Authorization: Bearer 你的_API_Key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "一张干净科技风的 API 服务宣传海报，中文标题 FluterAPI",
    "size": "1024x1024"
  }'
生图耗时可能比文字请求长，尤其是 2K/4K。本站单独提供了长超时图片入口，但普通用户通常仍填写 https://api.fluterapi.top/v1 即可。
如果提示 Image generation is not enabled for this group，说明当前 Key 的分组没开生图。请换生图分组的 Key，或联系管理员调整。

常见报错

401 Unauthorized / INVALID_API_KEY

API Key 填错、复制不完整、Key 被删除，或者把登录密码当成 API Key 了。回到 API 密钥页面重新复制 Key。

429 Too Many Requests

请求太频繁、并发太高，或者上游临时限流。等一会儿再试，降低并发，或换更稳定的通道。

502 / 503

通常表示上游服务临时不可用、账号池异常或请求时间太长。先等 1 分钟重试；持续出现时，把模型名、请求路径、报错时间发到群里。

模型列表能看到，但调用失败

模型列表说明站点知道这个模型名，实际调用还要看你的 Key 分组和上游是否可用。可以先换同系列模型测试。

生图返回只有 URL，b64_json 为空

这取决于上游返回方式。有些上游只给 URL，有些会上返回 b64_json。客户端如果必须读取 b64_json，需要换支持 b64_json 的生图通道。
